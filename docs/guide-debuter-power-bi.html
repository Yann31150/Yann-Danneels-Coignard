Débuter avec Power BI

Guide pratique pour créer vos premiers tableaux de bord

Par Yann Danneels-Coignard - Data Analyst

1. Qu'est-ce que Power BI ?

Power BI est un outil de visualisation de données développé par Microsoft qui permet de créer des tableaux de bord interactifs et des rapports à partir de vos données.

Avantages :

  • Gratuit : La version Desktop est entièrement gratuite
  • Facile à utiliser : Interface intuitive, pas besoin de coder
  • Puissant : Gère des millions de lignes de données
  • Connectivité : Se connecte à Excel, SQL, fichiers CSV, APIs, etc.

2. Installation de Power BI Desktop

Étape 1 : Téléchargement

  1. Allez sur powerbi.microsoft.com
  2. Cliquez sur "Télécharger gratuitement"
  3. Choisissez "Power BI Desktop"
  4. Téléchargez et installez l'application

Étape 2 : Première ouverture

À l'ouverture, vous verrez l'interface principale avec :

  • Le ruban en haut (comme Excel)
  • Les volets à droite (Champs, Visualisations, Filtres)
  • La zone de travail au centre

3. Importer vos premières données

Depuis Excel :

  1. Cliquez sur "Obtenir des données"
  2. Sélectionnez "Excel"
  3. Choisissez votre fichier
  4. Sélectionnez les feuilles à importer
  5. Cliquez sur "Charger"

Depuis un fichier CSV :

  1. Cliquez sur "Obtenir des données" → "Texte/CSV"
  2. Sélectionnez votre fichier CSV
  3. Vérifiez l'aperçu des données
  4. Cliquez sur "Charger"

4. Créer votre premier graphique

Étape par étape :

  1. Sélectionnez un type de visualisation dans le volet "Visualisations" (ex: Graphique en colonnes)
  2. Glissez un champ dans "Axe" (ex: Mois)
  3. Glissez un champ dans "Valeurs" (ex: Ventes)
  4. Votre graphique apparaît automatiquement !

Types de graphiques recommandés :

  • Colonnes : Pour comparer des valeurs
  • Lignes : Pour voir des tendances dans le temps
  • Camembert : Pour montrer des proportions
  • Tableau : Pour afficher des données détaillées

5. Personnaliser vos visualisations

Formatage :

  • Cliquez sur votre graphique pour le sélectionner
  • Dans le volet "Visualisations", cliquez sur l'icône "Format" (rouleau de peinture)
  • Personnalisez les couleurs, les titres, les axes

Astuces :

  • Utilisez des couleurs cohérentes dans tout votre tableau de bord
  • Ajoutez des titres clairs à chaque visualisation
  • Limitez-vous à 3-5 graphiques par page pour la clarté

6. Créer des mesures avec DAX

DAX (Data Analysis Expressions) est le langage de Power BI pour créer des calculs.

Mesures de base :

  • Total Ventes : =SUM(Table[Ventes])
  • Moyenne : =AVERAGE(Table[Ventes])
  • Compte : =COUNT(Table[ID])

Comment créer une mesure :

  1. Clic droit sur votre table → "Nouvelle mesure"
  2. Écrivez votre formule DAX
  3. Donnez un nom à votre mesure
  4. Utilisez-la dans vos visualisations

7. Créer un tableau de bord complet

Structure recommandée :

  1. Titre en haut : Nom de votre tableau de bord
  2. KPIs principaux : Cartes avec les chiffres clés
  3. Graphiques de tendance : Évolution dans le temps
  4. Répartition : Graphiques en camembert ou barres
  5. Tableau détaillé : Données brutes si nécessaire

Bonnes pratiques :

  • Organisez les éléments de gauche à droite, de haut en bas
  • Utilisez des filtres pour permettre l'interaction
  • Testez votre tableau de bord avec des utilisateurs finaux

8. Publier et partager

Option 1 : Power BI Service (gratuit)

  1. Créez un compte gratuit sur powerbi.microsoft.com
  2. Dans Power BI Desktop, cliquez sur "Publier"
  3. Connectez-vous à votre compte
  4. Votre rapport est maintenant en ligne !

Option 2 : Exporter en PDF

  • Fichier → Exporter → PDF
  • Parfait pour partager des rapports statiques
